# Kevoth-Kuls Palace

**Region:** Numeria | **City:** Starfall

## Description

A large palace with multiple floors. Contains Garton's lab, the Dark Seers' chamber (north, leading downstairs), Kevoth-Kul's consort's quarters (southeastern corner), barracks, and a harem. Has central halls and guard stations.
