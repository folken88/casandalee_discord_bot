# Casandalee Personality Portal

A local web app for viewing and editing **Casandalee** personality files used by the Cass Discord bot. Each of her 72 past lives (plus goddess form) has a markdown file with identity, personality, speech style, Pathfinder stats, memory snippets, and timeline quotes.

## URL

- **Local:** [http://localhost:3960](http://localhost:3960)  
- When running in Docker (`cass-editor` service), the same port is exposed on the host.

You can link to this page from other projects (e.g. `http://your-host:3960/personality-portal.md` or the root for the editor UI).

## What it does

- **List** all personalities (goddess + lives 1–72) from `data/personalities/*.md`.
- **Edit** for each: name, class, alignment, birth year, personality text, speech style, tone, preferred emojis, Pathfinder stats (25-point buy), memory snippets (for daily “Name (life#): …” messages), and timeline quote (from the Iron Gods / campaign timeline).
- **Save** writes directly to the `.md` files; the bot watches that folder and reloads personalities on change.
- **New** — create a new past life (1–72) with a generated filename.

## Data location

- **Personality files:** `data/personalities/` (e.g. `31_cassantra.md`).
- **Timeline quotes** are generated by `tools/correlate-timeline-quotes.js` (Ollama); the portal never overwrites an existing timeline quote.

## Running

- **Docker:** `docker compose up cass-editor` (port 3960).
- **Host:** from repo root, `node tools/personality-editor/server.js` (ensure `data/personalities` exists).

## Linking from other projects

Use the portal URL as the base (e.g. `http://localhost:3960` for the editor, or `http://localhost:3960/personality-portal.md` for this doc). The editor is read/write; this markdown file is read-only documentation.
